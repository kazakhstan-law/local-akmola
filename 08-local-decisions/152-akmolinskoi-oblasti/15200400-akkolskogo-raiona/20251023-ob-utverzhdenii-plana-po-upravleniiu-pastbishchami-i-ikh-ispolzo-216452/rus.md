# Об утверждении Плана по управлению пастбищами и их использованию по Аккольскому району на 2025-2029 годы

В соответствии с Законами Республики Казахстан «О местном государственном управлении и самоуправлении В Республике Казахстан», «О пастбищах», Аккольский районный маслихат РЕШИЛ:

1. Утвердить прилагаемый План по управлению пастбищами и их использованию по Аккольскому району на 2025-2029 годы.

2. Настоящее решение вводится по истечении десяти календарных дней после дня его первого официального опубликования.

**Председатель Аккольского районного маслихата**

**С. Абаханов**
