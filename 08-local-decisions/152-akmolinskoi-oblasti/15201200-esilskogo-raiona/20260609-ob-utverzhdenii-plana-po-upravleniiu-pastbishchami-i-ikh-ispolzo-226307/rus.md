# Об утверждении Плана по управлению пастбищами и их использованию по Есильскому району на 2026-2030 годы

В соответствии с подпунктом 1) статьи 8 Закона Республики Казахстан «О пастбищах», Есильский районный маслихат РЕШИЛ:

1. Утвердить прилагаемый План по управлению пастбищами и их использованию по Есильскому району на 2026-2030 годы.

2. Признать утратившим силу решение Есильского районного маслихата «Об утверждении Плана по управлению пастбищами и их использованию по Есильскому району на 2025-2029 годы» от 5 декабря 2024 года № 8С-29/4.

3. Настоящее решение вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`an000`](rus/an000.md) | План по управлению пастбищами и их использованию по Есильскому району на 2026-2030 годы |
| [`an003`](rus/an003.md) | Данные о численности поголовья сельскохозяйственных животных, с указанием их владельцев |
| [`an003-part001-t001-r001`](rus/an003-part001-t001-r001.md) | `!` таблица 1, строки 1–1104 |
| [`an003-part001-t001-r002`](rus/an003-part001-t001-r002.md) | таблица 1, строки 1105–1642 |
| [`an003-part002`](rus/an003-part002.md) | Данные о количестве гуртов, отар, табунов, сформированных по видам и половозрастным группам сельскохозяйственных животных |
| [`an004`](rus/an004.md) | Приемлемые схемы пастбищеоборотов и карта с обозначением внешних и внутренних границ и площадей пастбищ, в том числе сезонных, объектов пастбищной инфраструктуры |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
