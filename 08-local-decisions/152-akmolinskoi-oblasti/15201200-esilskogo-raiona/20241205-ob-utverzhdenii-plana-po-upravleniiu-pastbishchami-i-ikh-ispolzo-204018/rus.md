# Об утверждении Плана по управлению пастбищами и их использованию по Есильскому району на 2025-2029 годы

В соответствии с подпунктом 1) статьи 8 Закона Республики Казахстан «О пастбищах», Есильский районный маслихат РЕШИЛ:

1. Утвердить прилагаемый План по управлению пастбищами и их использованию по Есильскому району на 2025-2029 годы.

2. Настоящее решение вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

**Временно осуществляющий полномочия председателя Есильского районного маслихата**

## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`part001`](rus/part001.md) | План по управлению пастбищами и их использованию по Есильскому району на 2025-2029 годы |
| [`part004`](rus/part004.md) | Данные о численности поголовья сельскохозяйственных животных, с указанием их владельцев |
| [`part004-part001-t001-r001`](rus/part004-part001-t001-r001.md) | `!` таблица 1, строки 1–763 |
| [`part004-part001-t001-r002`](rus/part004-part001-t001-r002.md) | `!` таблица 1, строки 764–1581 |
| [`part004-part001-t001-r003`](rus/part004-part001-t001-r003.md) | таблица 1, строки 1582–1644 |
| [`part004-part002`](rus/part004-part002.md) | Данные о количестве гуртов, отар, табунов, сформированных по видам и половозрастным группам сельскохозяйственных животных |
| [`part005`](rus/part005.md) | Приемлемые схемы пастбищеоборотов и карта с обозначением внешних и внутренних границ и площадей пастбищ, в том числе сезонных, объектов пастбищной инфраструктуры |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
