# Об утверждении Плана по управлению пастбищами и их использованию по району Биржан сал на 2026-2030 годы

В соответствии с подпунктом 15) пункта 1 статьи 6 Закона Республики Казахстан «О местном государственном управлении и самоуправлении в Республике Казахстан», с подпунктом 1) статьи 8 Закона Республики Казахстан «О пастбищах», маслихат района Биржан сал РЕШИЛ:

1. Утвердить прилагаемый План по управлению пастбищами и их использованию по району Биржан сал на 2026-2030 годы.

2. Отменить решение маслихата района Биржан сал № С-18/3 от 25 декабря 2024 года «Об утверждении Плана по управлению пастбищами и их использованию по району Биржан сал на 2025-2029 годы».

3. Настоящее решение вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

**Председатель маслихата района Биржан сал**

**Н. Куатова**


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |

| [`an004`](rus/an004.md) | Таблица 1. Данные о чиленности поголовья сельскохозяйственных животных, с указанием их владельца |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
