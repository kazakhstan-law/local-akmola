# Об утверждении Плана по управлению пастбищами и их использованию по городу Степногорску на 2025-2030 годы

В соответствии с Законами Республики Казахстан «О местном государственном управлении и самоуправлении в Республике Казахстан», «О пастбищах» Степногорский городской маслихат РЕШИЛ:

1. Утвердить прилагаемый План по управлению пастбищами и их использованию по городу Степногорску на 2025-2030 годы согласно приложениям к настоящему решению.

2. Настоящее решение вводится в действие по истечении десяти календарных дней после дня его первого офицального опубликования.

**Председатель городского маслихата**

**О.Джагпаров**

> *Утвержден решением*  
> *Степногорского городского маслихата*  
> *от 20 марта 2025 года*  
> *№ 8С-20/6*


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`an001`](rus/an001.md) | План по управлению пастбищами и их использованию по городу Степногорску на 2025-2030 годы |
| [`an002`](rus/an002.md) | `!` Сведения геоботанического обследования пастбищ |
| [`an002-part001`](rus/an002-part001.md) | Схема доступа к водоисточникам (озерам, рекам, прудам, копаням, оросительным или обводнительным каналам, трубчатым или шахтным колодцам), составленную согласно норме потребления воды. |
| [`an003`](rus/an003.md) | Сведения о скотомогильниках (биотермических ямах) |
| [`an003-part001-t001-r002`](rus/an003-part001-t001-r002.md) | таблица 1, строки 928–1008 |
| [`an006`](rus/an006.md) | Данные о количестве гуртов, отар, табунов, сформированных по видам и половозрастным группам сельскохозяйственных животных |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
