# Егіндікөл ауданының аумағында сайлау учаскелерін құру туралы

«Қазақстан Республикасындағы сайлау туралы» Қазақстан Республикасының 1995 жылғы 28 қыркүйектегі Конституциялық заңының 23 бабына сәйкес Егіндікөл ауданының әкімі ШЕШТІ:

1. Егіндікөл ауданының аумағында сайлау учаскелері қосымшаға сәйкес құрылсын.

2. Егіндікөл ауданы әкімінің «Егіндікөл ауданының аумағында сайлау учаскелерін құру туралы» 2014 жылғы 4 наурыздағы № 4 (нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде 2014 жылғы 14 наурызда № 4032 тіркелген, «Егіндікөл» аудандық газетінде 2014 жылғы 28 наурызда жарияланған) шешімінің күші жойылды деп танылсын.

3. Осы шешім Ақмола облысының Әділет департаментінде мемлекеттік тіркелген күннен бастап күшіне енеді және ресми жарияланған күннен бастап қолданысқа енгізіледі.
