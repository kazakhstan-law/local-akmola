# Сайлау учаскелерін құру туралы

«Қазақстан Республикасындағы сайлау туралы» Қазақстан Республикасының 1995 жылғы 28 қыркүйектегі Конституциялық Заңының 23 бабына сәйкес, Жақсы ауданының әкімі ШЕШІМ ЕТТІ:

1. Жақсы ауданы аумағында сайлау учаскелері осы шешімнің қосымшасына сәйкес құрылсын.

2. «Сайлау учаскелерін құру туралы» Жақсы ауданы әкімінің 2014 жылғы 3 наурыздағы № 04 (Нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде № 4047 болып тіркелген, 2014 жылғы 7 сәуірдегі «Жақсы жаршысы» аудандық газетінде жарияланған) шешімі күші жойылды деп танылсын.

3. Осы шешім Ақмола облысының Әділет департаментінде мемлекеттік тіркелген күнінен бастап күшіне енеді және ресми жарияланған күнінен бастап қолданысқа енгізіледі.
