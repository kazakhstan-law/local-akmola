# Міндетті медициналық сақтандыру мәселелері туралы

> *Ескерту. Күші жойылды - Ақмола облысы әкімінің 06.11.2004 № 52 шешімімен.*

Денсаулық сақтау саласындағы реформаларды әрі қарай тереңдету, облыста міндетті медициналық сақтандыру жүйесінің қызметін қамтамасыз ету мақсатымен 17 жылғы 1 шілдеден бастап мыналар бекітілсін:

<a id="para_1"></a>

1. Міндетті медициналық сақтандырудың аумақтық базалық бағдарламасы (1 қосымша).

<a id="para_2"></a>

2. Міндетті медициналық сақтандырудың базалық бағдарламасы шеңберіндегі медициналық қызметтердің тарифтері туралы ереже (2 қосымша).

<a id="para_3"></a>

3. Міндетті медициналық сақтандырудың базалық бағдарламасы шеңберіндегі медициналық қызметтердің Ақмола облысы бойынша тарифтері (3 қосымша).

<a id="para_4"></a>

4. Сақтандыру медицинасы мәселелері бойынша келісім комиссиясының қўрамы (4 қосымша).

<a id="para_5"></a>

5. Сақтандыру медицинасы мәселелері бойынша келісім комиссиясы туралы ереже (5 қосымша).

<a id="para_6"></a>

6. Облыс әкімінің кейбір шешімдері күшін жойды деп танылсын (6 қосымша).

<a id="para_7"></a>

7. Осы шешімнің орындалуына бақылау жасау облыс әкімінің орынбасары С.Ж. Жалмағамбетоваға жүктелсін.

**Облыс әкімі**

> Ескерту. Қосымшаны орыс мәтіннен қараңыз.
