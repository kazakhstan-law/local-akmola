# Правила предоставления малообеспеченным гражданам разовой выплаты для оформления удостоверений личности гражданина Республики Казахстан.

## 1. Общие положения.

1. Настоящие Правила предоставления малообеспеченным гражданам разовой выплаты для оформления удостоверений личности гражданина Республики Казахстан (далее - Правил) регулируют порядок организации выплат по бюджетной программе 258.51 «Социальные выплаты отдельным категориям граждан по решению местных представительных органов».

2. Правовой основой для принятия Правил являются статья 6 Закона Республики Казахстан «О местном государственном управлении в Республике Казахстан», Закона Республики Казахстан «О бюджетной системе».

<a id="p3"></a>

3. Действие правил не распространяется на отношения, регулируемые Законом Республики Казахстан «О государственной адресной социальной помощи».

## 2. Порядок осуществления выплат.

<a id="p4"></a>

4. Разовая выплата является одной из форм социальной защиты и предоставляется малообеспеченным гражданам с месячным среднедушевым доходом ниже черты бедности и не получающим адресную социальную помощь из-за отсутствия удостоверения личности и не имеющим номера социального индивидуального кода.

<a id="p5"></a>

5. Разовая выплата предоставляется малообеспеченным гражданам в денежной форме, на основании соответствующего заключения сельской (городской) участковой комиссии.

<a id="p6"></a>

6. На основании заявления гражданина, сельские (городская) участковые комиссии проводят проверку материально-бытовых условий и уровня обеспеченности, обратившихся за помощью и составляет соответствующий акт.

<a id="p7"></a>

7. По актам обследования формируются списки малообеспеченных граждан, нуждающихся в документировании - оформлении удостоверения личности гражданина Республики Казахстан, у которых имеется паспорт образца 1974 года. Списки заверяются акимами сельских (поселкового) округов и города Щучинска, отделением миграционной полиции Щучинского районного отдела внутренних дел и предоставляются в районный отдел труда, занятости социальной защиты населения.

<a id="p8"></a>

8. Размер разовой выплаты составляет 400 тенге и складывается из следующих расходов:

   Стоимость фотографий - 180 тенге

   Стоимость удостоверения личности - 165 тенге

   Стоимость ксерокопии - 35 тенге

   Государственная пошлина, изымаемая с физических лиц в Народном банке - 20 тенге

<a id="p9"></a>

9. Выплата осуществляется путем перечисления средств на расчетный счет районного отдела труда, занятости и социальной защиты населения.

## 3. Финансирование разовой выплаты.

<a id="p10"></a>

10. Финансирование расходов по разовой выплате производится в пределах средств, предусмотренных на эти цели районным бюджетом по бюджетной программе 258.51 «Социальные выплаты отдельным категориям граждан по решению местных представительных органов».

## 4. Контроль за осуществлением выплат.

<a id="p11"></a>

11. Контроль и отчетность по оказанию разовых выплат осуществляется в соответствии с Законом Республики Казахстан «О контроле за исполнением республиканского и местных бюджетов».
