# Сандықтау ауданы Новоникольск ауылдық округі елді мекендерінің көшелерін қайта атау туралы

«Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы» Қазақстан Республикасының 1993 жылғы 8 желтоқсандағы Заңының 14 бабының 4) тармақшасына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңының 35, 37 баптарына сәйкес, халықтың пікірін ескере отырып және Ақмола облыстық ономастика комиссиясының 2018 жылғы 5 қазандағы қорытындысы негізінде, Новоникольск ауылдық округінің әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. Сандықтау ауданы Новоникольск ауылдық округі Новоникольское ауылының Целинная көшесі Атамекен көшесіне қайта аталсын.

<a id="p2"></a>

2. Сандықтау ауданы Новоникольск ауылдық округі Құмдыкөл ауылының Набережная көшесі Ахмет Байтұрсынұлы көшесіне қайта аталсын.

<a id="p3"></a>

3. Сандықтау ауданы Новоникольск ауылдық округі Меньшиковка ауылының Интернациональная көшесі Бірлік көшесіне қайта аталсын.

<a id="p4"></a>

4. Сандықтау ауданы Новоникольск ауылдық округі Мысок ауылының көшелері қайта аталсын:

   1) Набережная көшесі Қазыбек би көшесіне;

   2) Садовая көшесі Болашақ көшесіне.

<a id="p5"></a>

5. Сандықтау ауданы Новоникольск ауылдық округі Смольное ауылының көшелері қайта аталсын:

   1) Школьная көшесі Мектеп көшесіне;

   2) Заречная көшесі Аққайың көшесіне.

<a id="p6"></a>

6. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p7"></a>

7. Осы шешім Ақмола облысының Әділет департаментінде мемлекеттік тіркелген күнінен бастап күшіне енеді және ресми жарияланған күнінен бастап қолданысқа енгізіледі.

**Новоникольск ауылдық округінің әкімі**

**К. Садуова**
